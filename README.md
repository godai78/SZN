# SZN
System zarządzania naborem tekstów

Maksymalnie prosty skrypt umożliwiający tworzenie bazy zgłoszonych w naborze tekstów, przydzielania statusów tekstom (otrzymane, przyjęcie, odrzucone, itp.) oraz przekazywanie zgłaszającym linka, pod którym mogą sprawdzić status.

Statusy można dodawać/zmieniać, ale należy wtedy uaktualnić je w sekcji 'count' która zlicza kolejkę plików.

W pliku głównym należy ustawić hasło (oraz ścieżkę, jeśli potrzeba).

Proszę o sygnał, w przypadku wykorzystania skryptu.
