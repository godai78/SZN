# SZN
## System zarządzania naborem tekstów

### Instalacja
1. Wyedytuj hasło i nazwę naboru w pliku 'index.php'.
2. Wgraj plik na serwer pod żądanym linkiem.

### Obsługa
1. Wejdź na link, gdzie został zainstalowany skrypt.
2. Podaj hasło ustawione w pliku.
3. Wpisz imię i nazwisko autora/autorki.
4. Skopiuj link i wyślij mailem.
5. W przypadku zmiany statusu zgłoszenia użyj listy rozwijanej.

### Korzystanie z linku.
Autorka/autor mogą na bieżąco podejrzeć stan zgłoszenia pod otrzymanym linkiem. Widzą czas od zgłoszenia oraz liczbę pozostałych tekstów czekających na sprawdzenie.
